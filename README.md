# Paper Lantern

本地优先、开源的论文阅读与文献管理工具。把论文收集、PDF 阅读、AI 解析、批注和研究笔记放在同一个工作区。

[使用指南](doc/usage.md) · [阅读 Agent](doc/reading-agent.md) · [API 说明](doc/api.md) · [浏览器扩展](extension/README.md) · [Research MCP](plugins/paper-lantern-research-mcp/README.md) · [开发说明](doc/development.md)

## 文献管理：从收集到整理

支持上传或拖入本地 PDF、通过 PDF 链接和 arXiv 导入，也能使用 Chrome / Edge 扩展从浏览器发送论文。

- **层级分类与多分类归属**：同一篇论文或笔记可归入多个主题，共享内容与阅读记录；重复导入同一 PDF 时合并分类归属。
- **搜索与排序**：按标题或分类搜索，按标题、上传时间、上次阅读时间整理列表。
- **阅读进度管理**：通过“最近”“待办”和已读标记安排阅读。
- **信息预览与引用**：在文献库预览论文信息和三行总结，复制 GB/T 7714、BibTeX、RIS、APA、MLA、IEEE 格式引用。

## PDF 阅读与 AI 解析

在双栏工作区中对照论文原文与 AI 解析，支持 PDF 目录、全文搜索、缩放和页码跳转。

- **结构化解析**：生成关键词及解释、基本信息、三行摘要、方法概览、逐项方法拆解和结论。
- **按目标自主解析**：基于 LangGraph，提供论文和最终目的后，Agent 自主读取原文、拆解方法并修正格式错误；单项刷新只生成对应成果。需要安装 [Agent 运行环境](doc/usage.md#阅读与-ai-解析)并使用支持原生工具调用的模型。
- **划词阅读**：选中文字即可高亮、评论、翻译或结合全文解释。
- **自动高亮重点**：点击 PDF 工具栏的高亮笔图标，让 LLM 挑选重要原文并保存为紫色高亮，自动将紫色标签命名为“自动高亮”；保留已有批注并跳过重复原文。[使用方法](doc/usage.md#自动高亮重要原文)
- **多线程讨论**：围绕论文持续追问，保存不同讨论线程与历史，支持流式回答。
- **自选模型服务**：支持兼容 OpenAI Chat Completions 的接口，可自定义模型与 AI 提示词。

## Markdown 笔记与研究整理

边读边记，也可以创建独立于论文的笔记，用于整理专题、研究日报或阶段报告。

- **Markdown 编辑器**：支持公式、表格、任务列表与自动保存。
- **文献关联**：在笔记中插入文献库中的论文，点击链接返回阅读器。
- **笔记讨论**：围绕笔记内容与 AI 讨论，继续梳理观点和问题。
- **导出与分享**：导出带批注的 PDF，或将 Markdown 笔记导出为 PDF。

## 阅读 Agent：查阅论文与整理文献库

点击文献库右下角可拖动的阅读助手图标，直接描述研究问题或整理目标。助手基于 **LangGraph + 官方 MCP Python SDK**，按任务选择工具，默认检索全部文献库，仅在用户明确指定分类时按分类筛选，支持在已有文献库中查找相关工作、比较方法与实验、整理专题报告，以及规划分类、标记、元数据和笔记修改。

- **查原文再回答**：检索摘要与正文，核对主要结论的逐字引文；回答中的 `C1`、`C2` 等编号链接到对应库内文章。
- **先看计划再修改**：涉及写入时展示具体对象和修改前后内容，可追问调整或取消，点击“确认执行”后才更新文献库。失败后可重新预览剩余操作，已成功步骤不会重复执行。
- **持续追问与任务恢复**：支持标题与历史管理、浮窗和侧边停靠；后台任务可在刷新后恢复进度，支持停止与检查点续跑。
- **保存报告笔记**：回答左下角的复制、保存或打开笔记图标在悬浮时显示。笔记使用报告标题，只保存正文与文章链接，不附加证据原文；关联笔记缺失时可重新创建。

![阅读 Agent：在文献库旁比较方法、查看编号引用并继续追问](doc/screenshots/reading-agent-research.jpg)

例如输入“比较相关文献的方法、实验条件与结论局限”，或“查看全部未分类论文，建议主题分类，先列计划等我确认”。当前 Agent 不开放文献导入下载、删除文献和去重合并；外部 MCP 客户端可用的工具以其独立文档为准。

首次使用需安装 Agent 的可选依赖，并在设置的“阅读机器人”模块配置支持原生工具调用的模型。[安装与完整说明](doc/reading-agent.md#安装与运行) · [日常使用步骤](doc/usage.md#阅读-agent查阅与整理)

## 本地存储与同步

论文、元数据、笔记、批注和讨论记录保存在本机，支持同步到本地文件夹或 WebDAV，便于配合网盘、NAS、坚果云和 Nextcloud 使用。支持手动同步及库变更后自动同步。

核心阅读、分类、笔记与批注功能无需配置 AI。使用 AI 功能时，相关文本会发送到你配置的模型服务，并可能产生费用；PDF 导出需要额外依赖。安装、配置、数据迁移和常见问题见[使用指南](doc/usage.md)。

## Research MCP：组合你的研究工作流

将 Paper Lantern 的 Research MCP 接口接入支持 MCP 的 AI 客户端后，你可以直接用自然语言描述研究任务，AI 客户端会根据你的指令自动调用工具，搜索本地文献、导入论文、创建分类、读取和新增论文高亮与批注、生成自动高亮、整理笔记，并将成果保存到 Paper Lantern，供你继续阅读、批注和更新。结合客户端自身的联网检索与定时任务能力，还可以让资料收集和整理自动衔接起来，例如下面几种用法。

### 让研究日报自己积累起来

结合 AI 客户端的联网检索与定时任务，每天追踪你关心的方向，核对来源、与已有记录去重，再通过 Research MCP 把结果写成独立笔记，按年月和周归档。例如，持续关注无人机与具身智能，把每天值得读的论文、关键方法和待跟进问题留在同一个文献库中。定时与检索由 AI 客户端提供，笔记则可以随时打开、补充和关联原文。

### 从一个问题整理出专题报告

也可以从一个具体问题开始尝试：比如“Flow Matching 在无人机中有哪些应用？”让 AI 客户端检索资料，导入可获取的论文，按研究方向分类、标记待读，再把技术路线、实验依据和局限整理成一篇带有库内论文链接的报告。读完原文后，你还可以继续补充批注，让报告随着理解和新资料一起更新。

MCP 提供了搜索、导入、分类、读写笔记等可以自由组合的工具。你可以从自己的一个重复动作出发：把本周笔记汇成组会提纲，按待办论文生成阅读计划，或为同一问题建立持续更新的方法对照表。试着把你的目标、筛选标准和希望保存的结果告诉 AI 客户端，再逐步调整成适合自己的研究流程。更多组合方式可以从 [Research MCP 工具文档](plugins/paper-lantern-research-mcp/README.md)开始探索。

### 为待读论文标出重点

可以告诉 AI 客户端：“找到文献库中的这篇论文，先预览自动高亮结果，确认后保存。”客户端可先用 `search_library` 找到论文 ID，再调用 `auto_highlight_paper`，通过 `save: false` 预览，默认调用则直接保存紫色高亮。筛选使用 Paper Lantern 设置中的模型服务，支持 MCP 的 Python 环境需安装 PyMuPDF；保存后刷新阅读器即可查看和继续批注。[MCP 调用示例](plugins/paper-lantern-research-mcp/README.md#automatic-highlights-v030)
