# 使用指南

[返回 README](../README.md) · [API 说明](api.md) · [开发说明](development.md)

## 安装与启动

### 1. 准备环境

需要：

- Python 3.9–3.12（当前上传实现使用标准库 `cgi`，Python 3.13 起已移除该模块）
- Chrome、Edge 等现代浏览器
- AI API Key（仅 AI 总结、翻译、解释和讨论等功能需要）

核心阅读和文献管理功能只使用 Python 标准库，无需先安装依赖。

### 2. 启动 Paper Lantern

在项目根目录运行：

```powershell
python server.py
```

然后在浏览器打开：

```text
http://127.0.0.1:8000/
```

> 请通过 `python server.py` 启动，不要直接双击 `index.html`，也不要使用普通静态服务器，否则文献导入、保存和 AI 功能无法使用。

### 3. 配置 AI

打开页面右上角的设置，填写：

- **AI Base URL**：默认为 `https://api.openai.com/v1`
- **AI Model**：默认为 `gpt-4o-mini`
- **AI API Key**：对应模型服务的密钥

Paper Lantern 使用兼容 OpenAI Chat Completions 的接口，因此也可以填写其他兼容服务的地址和模型名称。配置会保存在 `.env/paperlantern_config.json`。

可在“AI 接口”中点击“新建”，为不同模型或 API 服务分别填写配置名称、接口地址、模型和密钥。同一接口下的不同模型也可以保存为不同配置。“默认接口配置”用于没有指定独立接口的模块。

打开已有密钥的接口配置时，会自动读取该接口的可用模型；修改接口地址或密钥并离开输入框后，会重新加载。也可点击模型 ID 右侧的“加载模型”手动刷新，从与配置选择器相同的下拉框中选择模型。选择“手动输入模型 ID…”后可自由填写自定义模型。加载列表不会覆盖已填写的值；服务不支持模型列表或加载失败时，仍可手动填写服务商提供的模型 ID 并保存。

在“模块配置”中，可为论文概览、方法解析、关键词解释、划词翻译、划词解释、AI 讨论、论文查阅、讨论标题和自动高亮分别选择接口，并独立设置 Think。选择“跟随默认”会随默认接口切换，已指定接口的模块保持不变。翻译的 Think 默认关闭；旧版设置会保留已有 Think 行为。删除某组接口时，引用它的模块会改为跟随默认接口。

每组配置的密钥独立保存，密钥输入框留空会保留该组原有密钥；“测试连接”只测试当前组。“删除配置”会移除当前组，至少保留一组。旧版单组配置会自动作为“默认配置”保留。

修改 Python 后必须重启服务，再刷新页面。如果提示“后端未保存多配置”，说明仍连接到旧版服务；前端会保留未保存的密钥，并提示重启，不会显示保存成功。

不配置 AI 也可以正常导入、分类和阅读论文，以及使用笔记与批注功能。

## 日常使用

### 导入论文

在文献库首页点击上传入口，可选择以下方式：

- **上传本地 PDF**：选择文件，或把 PDF 拖入上传区域。
- **通过链接导入**：粘贴 PDF 直链、arXiv 摘要页链接或 arXiv PDF 链接。
- **通过浏览器扩展导入**：在网页或 arXiv 页面上一键发送到 Paper Lantern，安装方法见[浏览器扩展](#浏览器扩展)。

导入后，可以在首页搜索论文、创建分类，并通过论文卡片菜单管理分类归属或删除论文。

### 管理文献与独立笔记

- 使用分类整理论文和笔记，并按标题、上传时间或上次阅读时间排序。
- 文献库搜索支持标题、作者姓名、标志名称、分类和关键词，不区分英文大小写。可用空格组合条件，例如 `Hafner 精读`；标志搜索只匹配当前已添加的标志。
- 论文阅读器和笔记页左侧文献库的搜索固定覆盖整个文献库，不受当前分类、“最近”或“待办”限制；显示匹配条目数量，清空搜索后恢复原来的列表范围。
- 论文和笔记均可同时属于多个分类。在首页条目菜单或阅读器侧栏的条目菜单中选择“分类”，打开“管理分类”窗口，勾选或取消勾选后保存；清空选择会归入“未分类”。
- 拖入分类表示增加归属。移除或调整分类均在“管理分类”窗口中完成；取消原分类并勾选目标分类即可移动归属。删除分类会保留条目的其他归属。
- 全库、父分类、“最近”“待办”和笔记中的文献选择器均按文章 ID 去重；同一 PDF 重复导入会给已有文章增加指定分类。
- 列表中的“标志”列统一管理“已读”“待办”和自定义标志。点击后可多选或取消勾选；输入名称可创建并添加“精读”“待复现”等自定义标志，之后可在其他文献上复用。标志仅保存在本机。
- “待办”始终显示在标志菜单中；其他标志默认只展示文献库中仍有条目使用的标志。输入名称搜索可重新添加已隐藏的标志，不会重复创建同名标志。
- 勾选多篇文献后，点击多选工具栏中的“标志”，可批量添加、移除或新建标志。部分文献已添加时会显示横线和数量；勾选会添加到全部选中文献，取消勾选会从全部移除，其他标志保持不变。保存后立即更新列表中的标志，保留菜单和多选状态，不刷新页面。
- 点击标志菜单中名称左侧的图标，在左侧面板中选择旗帜、星标、书签、圆点、爱心、闪电、完成或标签，也可设置预设或自定义填充色。图标和颜色会立即应用于所有同名标志，并保存在本机。
- 点击列表表头的“标志”可以筛选论文；支持多选，匹配任一所选标志，并与当前分类和搜索条件叠加。表头会提示已选数量，可在菜单中清除筛选；没有匹配结果时也可直接清除。
- “最近”和“待办”入口可以快速筛选内容；取消“待办”标志后，条目会从待办列表移出。
- 点击首页的“新建笔记”，可创建不依附于论文的 Markdown 笔记，并围绕笔记内容与 AI 讨论。
- 在论文信息区点击 Citation，可复制 GB/T 7714、BibTeX、RIS、APA、MLA 或 IEEE 格式的引用信息。

### 阅读与 AI 解析

点击论文进入阅读器。PDF 显示在左侧，论文信息和阅读工具位于右侧。

- 使用 AI 生成关键词、基本信息、三行摘要、方法概览、方法拆解和结论。
- 点击相应区域的刷新或解析按钮，可重新生成内容。
- 在讨论区围绕当前论文提问；不同讨论线程及其历史会自动保存。
- 发送按钮左侧显示当前讨论模型名称，可下拉选择已保存的模型。这里只更新“AI 讨论”的接口选择，保留其 Think 设置，不改变默认接口、论文查阅、讨论标题和其他模块的配置；笔记讨论使用同一选择。
- 点击讨论输入框左下角的「＋」，可用与笔记相同的目录、搜索菜单加入其他论文（单条消息最多 12 篇）。论文以作者名称或标题显示在输入区，点击可查看三行摘要或跳转到论文，点击「×」可移除；发送按钮位于右下角。已发送的论文链接会随消息保存，重新打开对话后仍可查看。
- 加入论文时会复用已有三行摘要；没有完整摘要时，会通过一次 LLM 调用快速生成并保存摘要，准备完成前暂不可发送。正文优先使用文本缓存，没有缓存时尝试用 PyMuPDF 提取 PDF；无法读取时会显示错误，可先打开论文完成文本提取，再移除并重新加入。
- 主模型接收当前对话中已加入论文的编号、标题和摘要，可直接回答，也可指定论文和问题，由使用独立上下文的模型查阅正文后返回答案，再决定是否继续查阅。主对话使用“AI 讨论”的模块设置，查阅正文使用“论文查阅”的设置，引用论文摘要使用“论文概览”的设置。最多查阅 4 轮，每轮最多 4 个问题，收集完资料后才流式输出最终回答，引用使用 `[论文N]` 和标题（编号以本次回答为准）。独立笔记讨论也可加入论文，当前笔记仍为主要上下文。
- 扫描版 PDF 通常没有可提取的文字，因此 AI 解析、翻译和解释可能无法正常工作。

AI 请求使用你配置的模型服务，并可能产生对应账号的费用。

### 划词、批注与翻译

在 PDF 中选中文本后，可以：

- 添加高亮；
- 写评论；
- 翻译选中文字；
- 让 AI 解释这段文字在论文中的作用。

高亮、评论和翻译结果会保存在当前论文目录中。需要分享或归档时，可从论文卡片菜单导出带批注的 PDF。

### 自动高亮重要原文

在设置中配置 AI 后，打开一篇有文本层的 PDF，点击上方工具栏中的“自动高亮重要原文”（带星号的高亮笔图标，位于全文搜索按钮左侧）。Paper Lantern 会提取整篇论文的分页文字，交给设置中的 LLM 挑选核心贡献、关键方法、实验结果、结论和局限中的重要原文，再将能够精确定位的文字标为紫色并自动保存。

处理中按钮会暂时禁用，页面状态会提示当前进度；完成后显示新增高亮数量。已有高亮、评论和翻译会保留，相同页上已经高亮的相同原文不会重复添加。自动高亮可以继续改色、添加评论或删除，操作方式与手动高亮相同。

成功新增并保存高亮后，评论界面中的紫色标签会自动改名为“自动高亮”。鼠标悬停在颜色标签上时会显示铅笔按钮；点击后可原地修改含义，回车或移开焦点保存，Esc 取消。自定义颜色含义保存在当前浏览器，对该浏览器中的所有论文生效。

该功能需要至少 80 字符、最多 50 万字符的可提取文字。扫描版 PDF 需要先做 OCR；无法唯一、精确定位的引文会跳过。如果没有新增高亮，可能是没有合适的原文、候选内容已经高亮，或无法精确定位，具体原因会显示在页面状态中。阅读器使用浏览器提取文字，无需为此安装 PyMuPDF。

也可以通过 Research MCP 调用 `auto_highlight_paper`，直接为文献库中的论文生成并保存高亮，或用 `save: false` 预览。MCP 方式需要在运行插件的 Python 环境中安装 PyMuPDF，详见下方 [MCP 与开发](#mcp-与开发)。

### 写阅读笔记

阅读器内置 Markdown 笔记编辑器，支持公式、表格和任务列表，并会自动保存到当前论文的 `notes.md`。

导出带批注的 PDF 或将 Markdown 笔记导出为 PDF，需要安装额外依赖：

```powershell
pip install pymupdf markdown-it-py matplotlib
```

其中 `matplotlib` 用于渲染 `$...$` 和 `$$...$$` 公式；未安装时，公式会以纯文本输出。

## 同步与备份

在页面右上角的设置中选择同步方式：

- **本地文件夹**：适合网盘客户端目录、移动硬盘或 NAS 挂载目录。
- **WebDAV**：适合坚果云、Nextcloud 等支持 WebDAV 的服务。

配置后，可点击文献库右上角的同步按钮手动同步。开启“库变更后自动同步”后，上传论文、移动分类或保存批注和讨论时会尝试自动同步。

使用坚果云时：

- 填写 WebDAV 地址，例如 `https://dav.jianguoyun.com/dav/PaperLantern`，不要填写分享链接；
- 使用坚果云生成的第三方应用密码，而不是登录密码。

同步内容包含论文 PDF、元数据、笔记、批注、讨论记录和同步索引。请使用可信的私有同步空间。

## 数据存放位置

首次加载旧版分类索引时，会自动升级多分类结构，并在文献库中保留 `library_db.v1.backup.json` 备份。

接口参数及多分类请求示例见 [API 说明](api.md)。

默认文献库位于项目内的 `literature_library/`：

```text
literature_library/
├── library_db.json                  # 分类和文献索引
├── paperlantern-sync-index.json     # 同步索引
└── papers/
    └── <paper-id>/
        ├── paper.pdf                # 原始 PDF
        ├── metadata.json            # 标题、分类、摘要和基本信息
        ├── notes.md                 # Markdown 阅读笔记
        ├── highlights.json          # 高亮、评论和翻译
        ├── discussion.json          # 讨论线程
        └── extracted_text.txt       # PDF 文本缓存
```

如需将文献库放在项目外，可在启动前设置 `PAPER_LIBRARY_DIR`：

```powershell
$env:PAPER_LIBRARY_DIR = "E:\your\paper_library"
python server.py
```

`.env/`、`.cache/` 和 `literature_library/` 已被 Git 忽略，以降低误提交密钥和私人论文的风险。迁移或重装前，仍建议单独备份文献库目录。

## 浏览器扩展

项目自带 Chrome/Edge 扩展，可导入当前 PDF、arXiv 页面或网页中的 PDF 链接。

1. 先启动 Paper Lantern。
2. 打开浏览器的扩展管理页面，例如 Chrome 的 `chrome://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择项目中的 `extension/` 文件夹。
5. 在 PDF 或 arXiv 页面点击扩展图标，或右键 PDF 链接后选择导入。

扩展默认连接 `http://127.0.0.1:8000`，可在扩展弹窗中修改地址。

## 高级配置

除了在页面中设置，也可以在启动前使用环境变量提供默认值：

```powershell
$env:AI_API_KEY = "sk-your-real-api-key"
$env:AI_MODEL = "gpt-4o-mini"
$env:AI_API_BASE_URL = "https://api.openai.com/v1"
$env:PORT = "8000"
$env:PAPER_LIBRARY_DIR = "E:\your\paper_library"
python server.py
```

同步相关环境变量：

```text
CLOUD_SYNC_PROVIDER=local
CLOUD_SYNC_LOCAL_DIR=E:\paperlantern-sync
CLOUD_SYNC_WEBDAV_URL=https://dav.example.com/PaperLantern
CLOUD_SYNC_WEBDAV_USERNAME=your-user
CLOUD_SYNC_WEBDAV_PASSWORD=your-app-password
CLOUD_SYNC_AUTO_PUSH=true
```

如果修改了 `PORT`，请使用对应端口访问页面，并同步修改浏览器扩展中的服务器地址。

## 常见问题

### 页面可以打开，但无法导入或保存

确认是通过 `python server.py` 启动，并从终端显示的 `http://127.0.0.1:<端口>/` 访问，而不是直接打开 HTML 文件。

### AI 功能提示未配置或请求失败

检查设置中的 Base URL、模型名称和 API Key。Base URL 可以填写服务根地址，也可以填写以 `/chat/completions` 结尾的完整地址。

### PDF 没有文字，无法总结或翻译

当前文字提取依赖 PDF 自带的文本层。扫描版 PDF 需要先通过其他工具完成 OCR。

### 是否适合部署到公网

当前项目面向个人本地使用，没有提供多用户鉴权、权限隔离或公网部署加固，不建议直接暴露到公网。


## MCP 与开发

本地 MCP 插件可供 AI 客户端搜索文献、导入论文、管理分类、自动高亮和撰写笔记，工具与参数见 [Research MCP 文档](../plugins/paper-lantern-research-mcp/README.md)。

自动高亮使用 Paper Lantern 设置中的 AI 服务，插件会直接读取文献库里的 PDF，不需要保持 HTTP 服务或阅读器打开。先在 MCP 所使用的 Python 环境中安装依赖，并在更新插件后重启或重新连接 MCP：

```powershell
python -m pip install pymupdf
```

用 `search_library` 找到论文 ID 后，通过 MCP 的 `tools/call` 调用：

```json
{"name":"auto_highlight_paper","arguments":{"id":"<论文ID>"}}
```

默认合并保存紫色高亮；将参数改为 `{"id":"<论文ID>","save":false}` 可预览原文和坐标，不写入文件。预览仍会调用配置的 LLM。返回中包含新增或预览的高亮组数、重复与未匹配数量，以及 `colorMeaning: "自动高亮"`。保存后刷新已打开的阅读器查看结果；没有自定义含义时，紫色标签显示为“自动高亮”。

AI 提示词位于 `prompts/ai/`，可以按阅读习惯修改。项目无需前端构建；代码结构、模块职责和测试命令见[开发说明](development.md)。
